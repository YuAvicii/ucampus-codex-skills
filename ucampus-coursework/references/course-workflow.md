# 网页作答与验收

## 打开网站与登录

- 用当前可操作的浏览器打开 [U校园网页版](https://uai.unipus.cn/)。浏览器中已有 U校园课程或习题时，沿用该标签页，保留当前进度和作答上下文。
- 查看实际页面。如果出现登录入口或统一登录页，保留该页面，提示用户「请在打开的 U校园网页完成登录，看到『我的课程』后告诉我，我会继续作答。」登录和身份验证由用户在网页上完成。
- 等用户完成后，重新读取同一标签页。确认「我的课程」可访问或已经进入目标课程后，继续用户指定的在线流程。若打开时就已登录，直接进入课程。会话过期时回到这一步，恢复后重新检查刚才的题目和作答状态。

## 确定操作范围

- 在用户指定的浏览器里使用支持的浏览器操作工具。根据当前标签和页面可见控件定位，不复用旧会话的标签 ID、课件链接参数、元素索引或坐标。
- 「学习记录」看总进度、成绩和各单元进度。「教程目录」展开指定单元，记录缺项的完整路径、必修标记和状态。同一单元可能有多个 Task 2。
- 一次提交后保留题目路径、已答数量与分数。重试前回看状态。若平台允许重做，先核对是否会替换原成绩及用户要求。

## 分题型操作

| 题型 | 作答与核验 |
| --- | --- |
| 选择、判断、多选 | 对齐题干与选项文字。「A/B/C」只在页面顺序与参考材料一致时直接使用。多选提交前核对选项数。 |
| 填空 | 单词清除首尾空格，按空逐一填写。短语和句子的空格、标点、大小写按指示和原文。检查填写后页面确实保留值。 |
| 拖拽、排序、匹配 | 看左右标签文字和落点，按页面控件操作。提交前逐对核对分组与顺序。 |
| 讨论、主观题 | 用题目要求的语言和篇幅作答。范例中的虚构经历要标注。课程讨论可被同学看到，发布前核对用户授权和目标讨论区，发布后确认帖文出现。 |
| 视频、微课、阅读 | 按页面正常播放或阅读，查看页面要求和完成状态。播放结束或页面停留只作为过程中信号，最终以目录记录为准。 |
| 口语 | 由口语录音技能处理。普通录音先确认停止再查看分数；角色扮演要等系统走完全部轮次。 |

## 页面中断和最终验收

- 出现安全验证码时按使用工具的当次确认要求处理，或交由用户在网页中完成。会话过期时按[打开网站与登录](#打开网站与登录)恢复，再回到当前项目检查状态。
- 「已作答」与点击过题、已选中选项、已上传文件或已经录入不同。对考试型页面查看「答题小结」和未作答数。必要时回目录看任务状态，以排除仅保存草稿的情况。
- 如果题目分数达标与完成进度有不同门槛，按当前站点明示的规则判断。对已经全部作答、仍未完成的项目，查必修、解锁条件、提交状态，避免盲目反复重做。
- 结束时用新的学习记录核对目标单元。目标是课程 100% 时，核对总进度和所有指定单元行。在进度未达标时列出已核实的缺项和实际阻碍。
