# U校园课程作答

**适用范围** 仅适用于 《新探索研究生英语（基础级）视听说教程》 Unit 1–6。

1. 启动在线课程任务时，用浏览器工具打开 [U校园网页版](https://uai.unipus.cn/)。如果已有 U校园课程或题目的标签页，沿用该页。按[打开网站与登录](references/course-workflow.md#打开网站与登录)确认登录后，从「我的课程」进入本教材对应的课程。只查进度时直接看「学习记录」。要求补齐时，用「教程目录」的必修标签和任务状态列出缺项；低分重做另按用户给出的分数线和范围处理。
2. 用单元名、章节名、板块、Task 编号和题干关键词共同匹配参考答案。先读[教材版本与答案索引](references/answer-index.md)，再打开对应答案页。不同版本、选项重排或题干不一致时，以当前题面和平台解析为准。开放题按题意写，样稿来自[作答示例](references/answer-examples.md)。
3. 按[网页作答和验收流程](references/course-workflow.md)操作。单词填空去掉首尾空格，每个单词放进对应空格；短语、整句按题面保留必要空格和标点。看不到原文或标准答案时标明待核对，遵循用户对留空的要求。
4. 需要复述、朗读、角色扮演或上传录音时，使用 [ucampus-speaking](../ucampus-speaking/SKILL.md)。先核对题目，再准备音频、录音和提交。
5. 每项以平台的答题小结、完成状态或已发布结果为依据。目标为全部完成时，返回学习记录核对总进度，并逐单元确认完成状态。单项得分和课程完成百分比分开报告。
