# U校园口语录音

**适用范围** 仅适用于 《新探索研究生英语（基础级）视听说教程》 Unit 1–6。

启动在线口语任务时，用浏览器工具打开 [U校园网页版](https://uai.unipus.cn/)，按[打开网站与登录](../ucampus-coursework/references/course-workflow.md#打开网站与登录)确认登录后进入本教材的目标题目。如果已在课程或题目页面，沿用当前页面。仅查台词或生成本地音频时，直接使用下方资料和脚本。

1. 先确认题型、目标英语文本、题号和可用录音方式。从[口语参考索引](references/oral-answer-index.md)找到相符条目，或使用用户提供的脚本和当前页面原文。听后复述只复述题目指定的说话人。
2. 如要提交，由用户指定是否使用本人声音或合成音频。有文件上传入口时，按题面接收的格式上传。只有麦克风入口时，使用用户允许的音频路径，比如在 Windows 用扬声器播放英文合成音频，由浏览器正常通过系统麦克风收录。本技能的脚本负责本地生成和播放音频。
3. 对照[逐题录音操作](references/recording-workflow.md)。普通题在播放结束后查看录音按钮，如果仍是停止键就立即点停；如果已经回到麦克风图标就看评分。角色扮演通常由网页控制多轮录音，等对话结束再提交。
4. 在题目页确认录音可回放、每一条有效评分及答题小结。遇到零分或低分，先查台词、麦克风和录音时长，再按当前页面允许的方式重试。
